# Basics
The 0-current_working_directory script prints the absolute path of the current working directory.
The 1-listit script lists the contents of the current directory.
The 2-bring_me_home script changes the current working directory to the user's home directory.
The 3-listfiles script displays the current directory contents in long format.
The 4-listmorefiles script displays the current directory contents, including hidden files, in long format.
The 5-listfilesdigitonly script lists the current directory contents in long format, including hidden files and numeric user and group IDs.
The 6-firstdirectory script creates /tmp/my_first_directory.
The 7-movethatfile script moves /tmp/betty into /tmp/my_first_directory.
The 8-firstdelete script deletes /tmp/my_first_directory/bettyl.
The 9-firstdirdeletion script deletes /tmp/my_first_directory.
The 10-back script changes the working directory to the previous directory.
The 11-lists script lists the current directory, its parent, and /boot in long format, including hidden files.
The 12-file_type script prints the file type of /tmp/iamafile.
The 13-symbolic_link script creates a symbolic link named __ls__ to /bin/ls.
The 14-copy_html script copies newer HTML files from the current directory to its parent.
The 15-lets_move script moves files beginning with an uppercase letter into /tmp/u.
The 16-clean_emacs script deletes files in the current directory whose names end with a tilde.
The 17-tree script creates the nested directories welcome/to/school.
